Latest eight device fields

ADC fields are manufacturer-described lightly filtered values, not unprocessed electrode voltages. Counts are not mV; 0 and 4095 are provisional boundary codes. Manufacturer power/level algorithms are not verified.

Bench observations · 2026-11-25

Three 10 s off-body tests showed that boundary-code occupancy followed the floating cable: CH1 90.33%, neither 0%, CH2 96.83%. Reception rates were 313.30, 297.78 and 277.85 frames/s. This supports a floating-input/interference explanation, not a human-use safety validation.

OLS · two-channel RMS regression

Import a CSV with all eight device fields plus a numeric target column (e.g. measured force) and preferably a trial column. The program fits an intercept and two RMS coefficients on non-overlapping windows, then evaluates held-out trials or chronological windows. No target is invented for live hardware data.
